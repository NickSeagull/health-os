# Health Meds — лекарства и протоколы

> **Профиль.** До чтения и записи определи активный профиль по
> `.claude/shared/profile-resolution.md`. Короткий путь `Data/X` в этом файле
> означает `Data/profiles/<активный>/X` — буквально по нему писать нельзя.
> Перед записью назови, в чей профиль она идёт.

## Назначение

Управление текущими лекарствами, БАДами и протоколами лечения. Расписание приёма, отслеживание курсов.

## Workflow

### Просмотр текущих

1. Прочитать `Data/medications/current.json`
2. Показать таблицу:

```
| Препарат | Дозировка | Время | С пищей | Причина | Курс до | Врач |
|----------|-----------|-------|---------|---------|---------|------|
```

3. Расписание по времени суток:
```
🌅 Утро:
  - Препарат А — 1 таб

🌙 Вечер:
  - Препарат Б — 2 таб
```

### Добавление препарата

Спросить:
1. Название
2. Дозировка (мг, мл, таб)
3. Частота (1 раз/день, 2 раза/день, по необходимости)
4. Время приёма (утро, день, вечер, перед сном)
5. С пищей или без
6. Причина назначения
7. Кто назначил (doctor_id из contacts.json)
8. Курс до (дата окончания, если есть)

→ Добавить в `Data/medications/current.json` → `medications[]` или `supplements[]`
→ Сгенерировать `id`: `med_XX` или `sup_XX`

### Завершение курса

1. Найти препарат в `current.json`
2. Изменить `status` → `completed`
3. Переместить запись в `Data/medications/history.json` → `completed_courses[]`
4. Добавить `completed_date`

### Взаимодействия

При добавлении нового препарата:
- Проверить список текущих
- Если знаешь о потенциальных взаимодействиях — предупредить
- Disclaimer: «Проконсультируйтесь с врачом о совместимости»

### Протоколы

Протокол = группа препаратов от одного врача:
```json
{
  "id": "prot_01",
  "name": "Лечение гастрита",
  "doctor_id": "doc_01",
  "medication_ids": ["med_01", "med_02"],
  "description": "Курс по назначению гастроэнтеролога",
  "started": "2026-03-01",
  "follow_up_date": "2026-04-01"
}
```

## Алерты

- Курс заканчивается через ≤3 дня → severity: medium
- Препарат без `until` и длительный приём (>3 мес) → напоминание «Проконсультируйся с врачом о продолжении»

## Правила

- Не рекомендовать препараты самостоятельно
- Не отменять назначения врача
- **Медданные не покидают каталог проекта** — запись PHI куда-либо вовне запрещена. Наружу, если это вообще нужно, идут только агрегаты: количества, статусы, метрики. Никаких названий препаратов, диагнозов, аллергенов, ФИО и дат рождения

⚕️ *Информация носит справочный характер. Для принятия решений о лечении обратитесь к врачу.*
